
# 🏠 House Price Prediction using Machine Learning

This project focuses on building a regression-based Machine Learning model to predict house prices using a real-world dataset. It covers the complete ML workflow—from data preprocessing and exploratory analysis to model training and evaluation.

The goal of this project is to strengthen understanding of regression techniques, feature engineering, and model evaluation metrics used in real-world problems.

# 📌 Project Overview

📊 Dataset: Real-world house price dataset (CSV)

🧠 Model Used: Linear Regression

🎯 Objective: Predict house prices based on multiple features

🛠️ Tools & Libraries: Python, Pandas, NumPy, Matplotlib, Scikit-learn
